# [U81206 【模板】链式前向星](https://www.luogu.com.cn/problem/U81206)

## 题目背景

模板题，无背景

## 题目描述

链式前向星模板题，读入n个点，m条边，以及flag，若flag==1则图有向，否则无向。对每个点输出它的每一条边。

## 输入格式

第一行三个数n,m,flag，题意如上所示
第2~1+m行，每行三个数，x,y,z，代表从x到y有一条长为z的边

## 输出格式

若flag=1则m行，flag=0则m*2行，每行三个数，即该点的编号、所指向点的编号，边的长度，先按第一个数升序排列，再以链式前向星中的顺序输出即可。
（其实就是i从1到n，再按顺序查找边输出即可）
特殊的，若该点无出边，单独一个空行

## 输入输出样例 #1

### 输入 #1

```
5 5 0
```

### 输出 #1

## 说明/提示

对于100%的数据，m<=4000000;l<=1e9;保证图连通，

```cpp
// #pragma GCC optimize("O3")
// #pragma GCC optimize("unroll-loops")
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
const ll N=1e5+5,M=2e6+5,mod=998244353,inf=1LL<<60;
const long double pi=acos(-1);
struct node {
    int to; // 终点
    int w; // 权值
    int next; // 下一条边的下标
}edge[M];
int head[N];
int cnt = 0;
void add(int u,int v,int w){
    edge[cnt].to = v;
    edge[cnt].w = w;
    edge[cnt].next = head[u];
    head[u] = cnt++; 
}
void solve(){
    memset(head, -1, sizeof head); // 初始化head数组
    int n,m,flag;
    cin >> n >> m >> flag;
    if(flag==0){
        for(int i = 0 ;i<m;i++){
            int x,y,z;
            cin >> x >> y >> z;
            add(x,y,z);
            add(y,x,z);
        }

    }else {
        for(int i = 0 ;i<m;i++){
            int x,y,z;
            cin >>x >> y >> z;
            add(x,y,z);
        }
    }
    for(int i = 1; i <= n; i++){
        int has_edge = 0;
        for(int j = head[i]; j != -1; j = edge[j].next){
            cout << i << " " << edge[j].to << " " << edge[j].w << "\n";
            has_edge = 1;
        }
        if(!has_edge){
            cout << "\n";
        }
    }
}

signed main(){
    ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
    cout << fixed << setprecision(10);
    int T=1;
    //cin >> T;
    while(T--) solve();
    return 0;
}
```
