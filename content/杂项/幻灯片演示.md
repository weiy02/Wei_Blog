# 幻灯片演示

这篇文章既是使用说明，也是一个可点开验证的例子：点标题旁的「演示」按钮（或按
<kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Alt</kbd> + <kbd>P</kbd>）就能看到效果。

<!-- 分页 -->

## 怎么分页

默认什么都不用做：文章里本来就在用的 `---` 分隔线**自动**成为分页符，
`##` 二级标题也自动另起一页（它同时充当那一页的标题）。

想完全自己说了算，就在文章里任意位置写一个分页标记：

```html
<!-- 分页 -->
```

只要出现过一次，`---` 和 `##` 就都不再自动分页，一切按标记来。
标记写在正文里是看不见的，不会留下一道横线。

## 逐条出现（fragment）

把注释写在要点**同一行**的行尾，属性就贴到那一条上（列表不会被拆开）：

```markdown
- 第一条要点 <!-- .element: class="fragment" -->
- 第二条要点 <!-- .element: class="fragment" -->
```

效果就是下面这样，按 <kbd>→</kbd> / <kbd>空格</kbd> 才一条条出来：

- 第一条要点 <!-- .element: class="fragment" -->
- 第二条要点 <!-- .element: class="fragment" -->
- 第三条要点 <!-- .element: class="fragment" -->

reveal 认识的其它 fragment 写法（`fade-up`、`highlight-red`、`strike`…）都能用：

- 这一段是淡入的 <!-- .element: class="fragment fade-up" -->
- 这一段会高亮成红色 <!-- .element: class="fragment highlight-red" -->
- 这一段会被划掉 <!-- .element: class="fragment strike" -->

整段一起出现也行 —— 注释单独一行，那就贴到**上一个**元素（这里就是整张列表）：

```markdown
- 甲
- 乙

<!-- .element: class="fragment" -->
```

- 甲
- 乙

<!-- .element: class="fragment" -->

## 这一页的样式：背景与过场

`<!-- .slide: ... -->` 贴的是**这一页**的属性，写在页面内容里任意位置即可：

```html
<!-- .slide: data-background-color="#1b3a4b" -->
<!-- .slide: data-transition="zoom" -->
<!-- .slide: data-auto-animate -->
```

当前这一页就换成深蓝背景看一下（`data-transition` / `data-auto-animate`
同理，只是没法在这一页里同时演示）：

<!-- .slide: data-background-color="#13303f" -->

这一段写在换过背景的页面上，可以对比看看背景是不是变了。

## 讲稿（演讲者视图）

在页面里写上备注，演示时按 <kbd>S</kbd> 会弹出演讲者视图（当前页、下一页预览、
计时器、讲稿），只有自己看得到：

```html
<!-- note: 这里写给自己的讲稿，观众看不到 -->
```

<!-- note: 这行字只出现在演讲者视图里 —— 按 S 键打开就能看到它。 -->

页面内容照旧，讲稿在观众屏幕上是完全不出现的。

## 顺手能用的几个键

| 按键 | 作用 |
|:---|:---|
| <kbd>→</kbd> <kbd>←</kbd> / <kbd>空格</kbd> | 上一页 / 下一页（含 fragment） |
| <kbd>O</kbd> 或 <kbd>Esc</kbd> | 俯瞰全部幻灯片 |
| <kbd>S</kbd> | 演讲者视图（含讲稿与计时） |
| <kbd>F</kbd> | 全屏开关 |
| <kbd>Alt</kbd> + 点击 | 放大局部，再点一次还原 |
| <kbd>B</kbd> / <kbd>.</kbd> | 黑屏（讲别的东西时用） |
| <kbd>?</kbd> | 全部快捷键 |
| <kbd>Esc</kbd> | 退出演示（在俯瞰视图里先退出俯瞰） |

## 装不下的一页会自动缩小

一页内容太长（比如好几个代码块）时，整页会等比缩到画布里，而不是被裁掉：

```python
def quicksort(items):
    """一页放得下的代码就是正常大小"""
    if len(items) <= 1:
        return items
    pivot = items[len(items) // 2]
    left = [x for x in items if x < pivot]
    mid = [x for x in items if x == pivot]
    right = [x for x in items if x > pivot]
    return quicksort(left) + mid + quicksort(right)


print(quicksort([3, 6, 1, 8, 2, 9, 4]))
```

真放不下的时候（缩得比原尺寸的 35% 还小），说明这一页该拆了 —— 用分页标记拆开。

## 一句话总结

- 分页：什么都不写也能用；想精确控制就写 `<!-- 分页 -->`
- 逐条出现：`<!-- .element: class="fragment" -->`
- 页面级设置：`<!-- .slide: data-... -->`
- 讲稿：`<!-- note: ... -->`

这些注释都是标准 HTML 注释，**在正常阅读模式下完全看不见**，不影响文章排版，
导出 PDF 也不会出现。
