## 修复「点演示卡纯色屏 + 刷新后非真全屏」

用户报告：点演示进全屏后卡在纯色背景无文字；退出刷新后进演示但只有视口全屏。**复现确认**（poison MathJax promise 后 click 按钮，headless/有头 Chrome 均复现）：

- **根因**：`enter()` 里 `await MathJax.startup.promise` 无超时。MathJax 走 cdn.jsdelivr.net（国内常挂起），promise 永不落定 → enter() 永远停在 await → 全屏 + 加载遮罩（#191919 纯色，0.85rem 小字看不出）。此时 presenting=false，Esc 退全屏不清 URL → ?slides=1 残留 → 刷新自动进演示（无手势被浏览器拒绝全屏 → 只有视口内全屏）。
- **关键认知**：Chrome 全屏中按 Esc，**keydown 不会送达页面**（浏览器截走退全屏）——Esc 退出演示的主入口是 `fullscreenchange`，不是 keydown 的 onEscape。
- **修复**（slides.js）：
  1. MathJax await 加 1.5s 超时（Promise.race）；deck 就绪后 `MathJax.typesetPromise([deck])` 补排公式
  2. 新增模块级 `cancelEntering()`：进入途中取消（收全屏、遮罩、history.back 清 ?slides=1）；入口两个：无全屏进入时 keydown Esc（onEnteringEscape），全屏进入时 fullscreenchange（onFullscreenChange 的 `exited && entering` 分支）
  3. `onFullscreenChange` 退全屏分支从 `teardown()` 改为 `requestExit()`（清 URL）；补 webkitfullscreenchange 监听（老 Safari）
  4. 无手势进入（刷新/分享链接）后挂一次性 pointerdown/keydown（排除 Esc）捕获监听，首次交互补发 `goFullscreen()`（手势在那一刻有效）
- **验证**（有头 Chrome + agent-browser，5 场景全过）：MathJax 挂起正常进入；加载中 Esc 干净取消（URL 清空、文章 15212 字符完整）；刷新进入后按键自动上真全屏；全屏 Esc 退出 URL 清空；完整回归字节级 identical。
