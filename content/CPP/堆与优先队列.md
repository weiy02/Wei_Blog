# 堆(Heap)
## 声明大根堆与小根堆

```cpp
#include<queue>
using namespace std;
int main(){
    priority_queue<int> q; // 默认声明的是大根堆
    priority_queue<int, vector<int>, greater<int>> q; // 声明一个小根堆
    return 0;
}
```
